# Verifier fixtures

Self-describing golden vectors for the `@arkova/verifier-cli` conformance suite.

## PROOF-08 dependency

The canonical golden vectors are owned by **PROOF-08** (a teammate's deliverable:
a fixtures dir + README of proof packets whose expected roots match
`services/worker/src/utils/merkle.ts` byte-for-byte). **As of this commit those
golden vectors are not yet present in the repo.** Until they land, this package
ships **local synthetic vectors** (`synthetic-vectors.json`) generated against
the same canonical `buildMerkleTree` routine, so the test suite runs today.

When PROOF-08 publishes its vectors, point the loader at that directory (or add
the file here) — every vector that satisfies the `VerifierFixture` interface
below (canonical `ARKV‖root` OP_RETURN, real headers + inclusion proofs) is
picked up automatically; no test changes required.

`synthetic-vectors.json` is **generated**, not hand-written — run
`node fixtures/generate-fixtures.mjs` to re-emit it. The generator builds real
double-SHA256 block headers + inclusion proofs and the canonical
`OP_RETURN <push> ARKV(4)‖root(32)` (no version byte), so the on-chain path is
exercised for real by `@arkova/verifier`'s `confirmInclusion`.

## Fixture interface (`VerifierFixture`, see `src/types.ts`)

Each fixture is fully self-contained — proof packet + the exact independent-node
**Esplora REST responses** (keyed by the path `confirmInclusion` requests) + the
expected verdict — so the suite verifies **fully offline**:

```jsonc
{
  "name": "odd-leaf-pass",
  "description": "what this vector exercises",
  "packet": { /* ProofPacket: fingerprint, merkle_root, merkle_proof[], tx_id,
                 block_height, block_timestamp, merkle_index, leaf_count,
                 op_return_payload (ARKV‖root) */ },
  "node": {
    "/tx/<txid>":               { /* EsploraTx: vout[].scriptpubkey, status{...} */ },
    "/block-height/<height>":   "<block hash hex>",
    "/block/<hash>/header":     "<160-hex 80-byte header>",
    "/tx/<txid>/merkle-proof":  { "block_height": 0, "merkle": [], "pos": 0 }
  },
  "expect": { "ok": true, "reasonIncludes": "optional substring on failure" }
}
```

`node` is optional; omit it for recompute-only (offline) vectors.

## Files

| File | Purpose |
|---|---|
| `manifest.json` | **S3-B: the SINGLE versioned fixture manifest.** Lists EVERY fixture (synthetic + adversarial + PROOF-08 corpus) with the exact expected `{verdict, reason_code}` from the FROZEN reason enum (`reason_enum_version` 1.0.0; mirrored in `src/lib/reason-codes.ts` and `packages/arkova-py/src/arkova/proofs.py`). Three runners obey it and must agree three-way: `test/manifest.test.ts` (TS), `packages/arkova-py/tests/test_proofs.py` (Python), and `scripts/parity-compare.mjs` (`npm run parity`). PROOF-08 vectors that cannot run through this CLI's pipeline are in `excluded[]` with a rationale + the covering adversarial fixture. |
| `synthetic-vectors.json` | 9 local synthetic vectors (3 pass, 6 fail: tampered fingerprint, CVE-2012-2459 forged self-pair, on-chain root mismatch, txid-inclusion mismatch, txid **body**-mismatch (exercises the `independent-node.ts:160` txid-binding guard directly — its body's own txid differs from the request), and a forged packet timestamp (§1.5: differs from the header-measured Network Observed Time → flagged + failed)). Generated by `generate-fixtures.mjs`. |
| `generate-fixtures.mjs` | Deterministic generator for `synthetic-vectors.json` (canonical OP_RETURN, real headers + inclusion proofs). |
| `adversarial-vectors.json` | **S3-B: 20 adversarial vectors authored INDEPENDENTLY from the bundle-format spec** (2 valid controls + 18 attacks: tampered fingerprint byte, wrong sibling order at BOTH tree layers, off-by-one leaf/pos index at both layers, truncated 79-byte header, wrong `ARKX` marker, marker-behind-junk-byte substring smuggle, height mismatch, reorg hash mismatch, receipt not found / unconfirmed, unsupported schema version, malformed fingerprint, empty-branch mismatch, forged signature, unresolvable signing key id). Each pins one frozen reason code. Emitted by `author-adversarial.py`. |
| `author-adversarial.py` | Clean-room Python author for `adversarial-vectors.json` — derives everything from the documented formats and shares ZERO code with `generate-fixtures.mjs` (that independence is the S3-B requirement: fixtures must not be mutations of the builder's output). Signature vectors embed the PROOF-08 corpus throwaway TEST key/bundle; `test/manifest.test.ts` pins them against the corpus so they cannot drift. |
| `signed-bundle.json` | An Ed25519 signed bundle wrapping a passing packet (for the optional signature check). |
| `published-keys.json` | `docs.arkova.ai/keys.json`-shaped key file (the public-key PEM lives here; a bare `*.pem` is intentionally not committed — the repo-wide secret-hygiene `.gitignore` rule ignores `*.pem`). |

All vectors are synthetic — deterministic sha256-of-seed values, obviously fake
ids, throwaway TEST keys only. No PII, no real org/user identifiers, no
production key material.

The synthetic responses use Esplora's REST shapes (`GET /tx/:txid`,
`GET /block-height/:h`, `GET /block/:hash/header`, `GET /tx/:txid/merkle-proof`;
Blockstream/mempool.space), the exact paths `@arkova/verifier`'s
`createEsploraFetch` hits against a real independent node in production.
