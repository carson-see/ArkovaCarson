## The load

`scripts/staging/targeted/cft-contract-surface-driver.ts`, one 12-probe cycle every ~9 minutes,
~80 cycles across the window. Each cycle:

1. `/health` on the rig worker.
2. Five contract calls through the **installed, `npm pack`-produced `arkova` tarball** — not repo
   source: `fingerprint`, `verify`, `getAnchor`, `verifyFingerprint`, `webhooks.list`.
3. `webhooks.create({ events: ['anchor.superseded'] })` through that same installed SDK, then
   delete.
4. A GoTrue org-admin sign-in (fresh every cycle — a soak outlives a 1 h access token).
5. A freshly minted SECURED anchor, then a real `POST /api/anchor/:id/supersede`.
6. **Two independent confirmations of the resulting webhook**: the worker's own
   `webhook_delivery_logs` row (`response_status=200`) and a read-back from the receiving endpoint.

First fully-green in-window cycle: `20260830T223741Z`, **ok=12 fail=0**. Per-cycle artifacts in
`evidence/load-<ts>.json`.

   project survived its fail-closed cleanup; Steps 2–6 were completed by hand following the
   script's own printed plan.

   without it the worker crash-loops on `config.ts`'s production `superRefine`.

   `CREATE INDEX CONCURRENTLY` statements and cannot go through `db push`; it was applied via the
   IPv4 session pooler and its ledger row inserted to match (STAGING_RIG.md gotcha #3).

   A durable `SUBMITTED` fixture carrying a `chain_tx_id` was seeded instead and the supervisor
   tops it up each cycle.
5. Rig GoTrue auth limits were raised (`rate_limit_token_refresh` 150→3600) so the full-parallel
   RLS suite could sign in. The first run's 11 failures were all `Request rate limit reached`, not
   fixture collisions.
6. The rig service is `--no-allow-unauthenticated`, so the driver sends its identity token in
   `X-Serverless-Authorization` and leaves `Authorization` for the app JWT.
7. `staging_deploy_log` does not exist on an isolated rig — the table is a shared-staging artifact
   and is not in `supabase/migrations/`. The Cloud Build id is cited instead, matching PR #2336's
   isolated-rig precedent.
