== 6. UNSOAKABLE-SURFACE NOTE (CLAUDE.md §1.12, T2) ==

   irreversible, is founder-reserved (npm account ownership), and has no staging analogue —
   there is no rig on which 'npm publish arkova@2.2.0' can be rehearsed and rolled back.
   What IS soakable, and what is exercised above and continuously by the rig driver, is the
   ARTIFACT the publish step would upload: the exact npm pack tarball, installed as a
   consumer would install it, exercised against a live Arkova API. No worker artifact is
   claimed for this PR — it deploys nothing to any running service.
