# Named acceptance matrix — future user-started session

Every live case below is **OPEN / NOT RUN**. This document defines proposed acceptance for existing commitments and recovered WIP; it does not claim deployed behavior, partner approval, issuer authority, current professional standing, or soak evidence. The future user-started session fills exact candidate/environment identities and records pass, fail, or open. Unknown people remain role owners marked **unassigned**. The [canonical recovery roadmap](https://docs.google.com/document/d/1IrpVfTPehIwIUbAntlsCQjsBq7hEqhN-RFow-8A_9Ac/edit) preserves the partner, issuer, email and meeting-source links. Historical local receipt names below identify supporting research, not files expected in a reviewer checkout: each executable requirement is stated here, while committed source-review evidence lives beside this file (`final-local-qualification.md`, `review-dispositions.md`, `drive-review.md`, `proof-sdk-evidence.md`, `parts5-6-review.md`, `0494-review.md`, and `packaged-clients.md`).

## Evidence record required for every case

Record case ID; exact commit/tree and deployed revision; actor, tenant and client artifact; prerequisite/config readback; sanitized action/input; visible result; durable backend/job evidence; negative or recovery witness; start/end; evidence path/hash; owner role; independent verifier; and `PASS`, `FAIL`, or `OPEN`. Never store tokens, secret values, raw customer documents, private tags, recipient identifiers, or signed receipt bodies.

## Stop rules

Stop the affected case on cross-tenant access, secret or recipient leakage, accepted altered proof, duplicate charge/email/key side effect, access surviving revocation, lost/corrupt data, unsupported credential or standing claim, a background effect outside the approved mode, a material external-review finding, two consecutive hourly Drive reconciliation failures without durable recovery, or an identity mismatch between tested and frozen artifacts. Keep partner/browser/issuer unavailability `OPEN`; never convert it to a pass.
