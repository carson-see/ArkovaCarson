## Root causes found and fixed 2026-08-29T23:04Z

1. **Sandboxed supervisor lineage (EPERM).** The supervisors launched at 10:41:52 / 10:42:23 / 10:42:29 local
   (PRs 2434, a DUPLICATE 2435, and 2437) inherited a filesystem sandbox from their launching shell and could
   not write to `/Volumes/Extreme/...`. Every cycle ran its probes, then died with
   `EPERM ... open .../evidence/pr-<n>/cycle-*.json` at `lib/common.mjs:117` (`writeCycle`), which is called
   BEFORE the summary `console.log`. So those cycles produced NO artifact and NO probe record: the exit code
   was rc=1 (crash), not rc=3 (deviation). Supervisors launched at 10:53:37 and 11:34:50 (2435, 2439, 2441)
   were detached via `detach.py` and wrote normally throughout. Discriminating signal: identical driver,
   identical target directory, different process lineage; running the same driver from an unsandboxed shell
   writes the artifact fine.
2. **Duplicate supervisor on PR 2435.** Two live supervisors (pid 45707 from 14:42:23Z and pid 85650 from
   14:53:37Z) were both running `driver-2435.mjs` against tag `pr-2435` and interleaving into one log. 45707
   was in the sandboxed lineage and produced ZERO artifacts for ~8h; 85650 is the one whose window matches
   `pr-2435/window.env`. 45707 killed 23:03Z. It generated real concurrent load against the rig for that
   period but no evidence — disclose as unartifacted background concurrency, do not claim it.
3. **PR 2434's local edge worker was down.** #2434 changes `services/edge/src/mcp-server.ts` (Cloudflare edge),
   so its driver drives a local `wrangler dev --local` workerd on 127.0.0.1:8795 plus `edge-fault-proxy.mjs`
   on :8811. wrangler was itself started from the sandboxed lineage and could not read the
   `node_modules` symlink into `/Volumes/Extreme`, so its bundle failed with `Could not resolve "zod"`;
   workerd listened but served nothing. Every 2434 cycle since ~14:49Z therefore recorded
   `edge.health ... TypeError: fetch failed` and 11 downstream `status=0` deviations — i.e. the PR's changed
   code never ran. Re-stood from an unsandboxed shell 23:03Z: `{"status":"ok","service":"arkova-edge"}`.
4. **Transient network blip ~22:58-23:00Z.** Simultaneously hit 2435, 2439, 2441 and the old 2437 supervisor.
   Signature: `gcloud auth print-identity-token` -> `[Errno 65] No route to host` to oauth2.googleapis.com,
   and `status=0` on the HTTP probes. Self-recovered within one cycle on every soak.
