## Current Sources

- **Jira SCRUM board** is the source of truth for story status, scope, parents,
  subtasks, and acceptance criteria: https://arkova.atlassian.net/jira/software/projects/SCRUM
- **Confluence space A** is the source of truth for story/topic documentation:
  https://arkova.atlassian.net/wiki/spaces/A
- **HANDOFF.md** is the short rolling operational snapshot for the current
  session/queue posture.
- **GitHub PRs** are the source of truth for branch/check/merge state.

## Why This Was Collapsed

The previous 118-line table claimed to be a "Single view of all remaining open
items" but was consolidated on 2026-03-27 from local Markdown and had drifted
from Jira, Confluence, and GitHub. Keeping duplicate status tables here wastes
context and creates bad handoffs.

For historical detail, use git history for this file. For current work, query
Jira/Confluence/GitHub directly.
