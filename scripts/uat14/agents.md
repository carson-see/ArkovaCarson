# UAT-14 diagnostics

`profile-avatar-readiness.ts` is an opt-in, bounded Playwright readiness check for the first avatar input. The tracked UAT-14 E2E fixture calls it before upload. Its post-timeout inspection lasts at most 500 ms. It classifies only coarse browser state and counts HTTP failures observed after helper registration; it cannot explain earlier login/navigation requests. Never add page text, screenshots, query strings, credentials, response bodies, or raw Playwright errors to its diagnostic. A timeout is not proof of a product defect. The failed timed hosted driver does not call this helper; a future driver must be reviewed and admitted separately. Local fixtures and tests do not replace hosted Auth/Storage acceptance or authorize editing/replaying a frozen soak attempt.
