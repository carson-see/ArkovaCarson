# UAT-23 local verification

`native-pg-activation-delivery.sh` creates and drops only a uniquely named local PostgreSQL database and rejects remote hosts. It applies the exact `0471` migration, races two service-role delivery claims, proves exactly one durable winner, verifies the loser receives the expected unique violation, and checks anon/authenticated ACL denial plus forced RLS. It executes the actual pre-UAT17 `0439` domain-association function and actual Auth-confirmation trigger against a minimal Auth fixture, proving `admin_provisioned` bulk recipients remain org-less while ordinary matching-domain accounts retain the base behavior. It also proves marker-only orphan recovery and denial without mutation for unmarked, confirmed, or already-member identities. It does not run GoTrue, send email, establish provider delivery, or replace staging qualification.
